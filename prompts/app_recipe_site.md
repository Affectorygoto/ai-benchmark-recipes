# アプリ開発系ベンチマークプロンプト

【ベンチマーク制約】  
本依頼はAIモデルの性能比較（ベンチマーク）です。**質問や確認は一切行わず、**不明点がある場合はこれまでの一般的なベストプラクティスに基づき、あなたの判断で自律的に完結させてください。

【実装環境の指定】

ファイル構成: index.html 1ファイルのみで構成。

使用技術: HTML5, Tailwind CSS (CDN利用), JavaScript (Vanilla JS)。

動作環境: 特殊なサーバー構築は不要。ブラウザでファイルを開くだけで全機能が動作すること。

【タスク：AIお料理レシピ検索サイトの構築】

機能: ユーザーが食材名を入力して検索すると、AIが提案したようなレシピ（タイトル、材料、手順）が画面に表示される機能。※API連携は不要。5つ程度のサンプルデータを内部に持ち、擬似的に動作させること。

デザイン: モバイル対応（レスポンシブ）。清潔感があり、食欲をそそるモダンなUI。

品質: 入力バリデーション（空欄時の警告）、検索中のローディング演出の実装。
